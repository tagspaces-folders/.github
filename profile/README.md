# TagSpaces - Tags on Files You May Organize

TagSpaces is a browser for your folders with tags you add. Search finds those tags. The files remain files. TagSpaces does not become the only copy of the document.

---

## Product Snapshot

Open a folder you own, tag a few files with words you will still understand next month, and search one of those words. If the file opens, you were looking at the real path. If you move the folder later, take the tag data with it or the search will miss files that are still on disk.

Preview a photo or a note to decide whether it is the one you wanted. Save edits in the program that owns that file type, under a new name if the original must stay. TagSpaces is not a reason to overwrite a camera file.

## Highlights

- Tags you type on files you may use
- Search by those tags
- A folder you choose, not every drive
- Preview without replacing the master
- Tag data you keep with the folder
- No claim on someone else's directory

---

## Live Production

Use it to mark a project: draft, sent, or source. Tag a small set first. A color or a word is enough. Do not import a library of tags from a pack you do not understand if it would rename how you find things.

Back up the folder, including the sidecar or database the app stores beside it. A copy of the documents without the tags is still the documents, but you will lose the labels. On a shared PC, close the app so private filenames are not left on screen.

---

## Words You Will Search

A tag you will not remember is a tag you will not find. Use plain words, apply them to a few files, and search before you tag the rest of the folder.

---

## Setup Path

Prerequisites: A folder of your files, and a few words you will actually search for.

1. Install TagSpaces and open that folder.
2. Tag three files with a word you choose.
3. Search that word and open one hit.
4. Close without saving over the original.
5. Copy the folder, including tag data, if the labels matter.

## Who Benefits

TagSpaces fits your own project folders and a search you define. It does not fit another person's files, a password stored in a tag on a shared disk, or a preview that you then save on top of the only original.

---

## Fixes

Search misses a file: the tags did not move with the folder, or you are in a different directory. The preview will not show a type: open it in the program that created it. You saved over the original: restore the copy and use a new name next time.
